# 우리 반 교실 관리 사이트

전자칠판·교사 PC·폰 어디서 열어도 같은 기록이 보이는 교실 관리 사이트입니다.

| 탭 | 하는 일 |
| --- | --- |
| **과제 체크** | 과제마다 학생 이름 칸이 있어요. 이름을 터치하면 완료(초록), 다시 터치하면 해제. 과제는 여러 개 만들 수 있어요. |
| **번호 뽑기** | 학생이 자기 이름을 누르면 남은 번호 중 하나가 뽑혀요(2초 연출). 결과는 자동으로 기록되고, 같은 번호·같은 학생 중복은 막혀요. |
| **수학 확인** | 분수 연산 마스터에서 **이전 등교일**에 수학을 안 한 학생 이름을 보여 줘요. |
| **우리 반** | 학생 명단(붙여넣기·분수 연산 마스터에서 가져오기), 설정, 엑셀(CSV) 내보내기, 백업. |

- 기록은 **Firebase(Firestore)** 에 저장돼요. 칠판에서 누르면 폰에도 바로 바뀌어요.
- 인터넷이 잠깐 끊겨도 과제 체크는 기기에 저장해 두었다가 연결되면 자동으로 올라가요. (번호 뽑기는 연결되어 있어야 해요)
- 사이트는 **Vercel** 에 올려요. 둘 다 무료 요금제로 충분해요.

> 잠금(비밀번호)이 없어서 사이트 주소를 아는 사람은 누구나 보고 고칠 수 있어요. 주소를 학생·외부에 공유하지 마세요.

## 1. 처음 설정 (한 번만)

### 1-1. Firebase 프로젝트 만들기

**분수 연산 마스터와 다른 새 프로젝트**를 만드세요. 같은 프로젝트를 쓰면 그쪽 무료 한도를 다 썼을 때 이 사이트도 멈춰요.

1. <https://console.firebase.google.com> → **프로젝트 추가** → 이름 예: `uriban-5-4` → Google 애널리틱스는 꺼도 돼요 → 만들기
2. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
3. Firestore 화면 위쪽 **규칙** 탭 → 내용을 모두 지우고, 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣기 → **게시**
4. 왼쪽 위 톱니바퀴 **프로젝트 설정** → 아래쪽 **내 앱** → 웹 아이콘 `</>` → 앱 닉네임 아무거나 → **앱 등록**
   (Firebase 호스팅 체크는 하지 마세요)
5. 화면에 나온 `const firebaseConfig = { ... }` 안의 값 6개를 복사해 둡니다.

### 1-2. 설정값을 사이트에 넣기

1. GitHub 저장소에서 [`public/js/firebase-config.js`](public/js/firebase-config.js) 를 열고 연필(✏️) 버튼
2. 빈 따옴표 `''` 안에 복사한 값을 하나씩 넣기

   ```js
   export const firebaseConfig = {
     apiKey: 'AIza...',
     authDomain: 'uriban-5-4.firebaseapp.com',
     projectId: 'uriban-5-4',
     storageBucket: 'uriban-5-4.appspot.com',
     messagingSenderId: '1234567890',
     appId: '1:1234567890:web:abcdef',
   };
   ```
3. **Commit changes** 로 저장

이 값들은 원래 웹사이트에 공개되는 값이라 GitHub 에 올려도 괜찮아요.

### 1-3. Vercel 에 올리기

1. <https://vercel.com> → **Continue with GitHub** 로 로그인
2. **Add New… → Project** → `blankchatbot` 저장소 옆 **Import**
3. Framework Preset 은 **Other** 그대로, 다른 칸은 건드리지 말고 **Deploy**
4. 1분쯤 뒤 나오는 주소(예: `https://blankchatbot-xxxx.vercel.app`)가 우리 반 사이트예요.
5. 전자칠판·PC·폰 브라우저에서 이 주소를 **즐겨찾기**

이후에는 GitHub 에 바뀐 내용이 올라가면 Vercel 이 자동으로 다시 올려요.

### 1-4. 사이트에서 반 설정

1. **우리 반** 탭
   - 학생 명단: `여러 명 한꺼번에 붙여넣기`(엑셀에서 번호·이름 두 칸 복사) 또는 `분수 연산 마스터에서 명단 가져오기` → **명단 저장**
   - 설정: 반 이름, 분수 연산 마스터 반 코드(교사 화면 위쪽 6글자), 등교 안 하는 날 → **설정 저장**
2. **과제 체크** 탭에서 `+ 과제 만들기`

## 2. 쓰는 법

### 과제 체크
- 위쪽 버튼으로 과제를 고르고, 이름 칸을 터치하면 완료 / 다시 터치하면 해제
- 아래 줄에 "아직: ○번 ○○○ …" 이 보여요
- **💾 저장하고 새 과제**: 지금 과제를 저장(지난 기록으로 보냄)하고 바로 다음 과제를 만들어요
- **📋 지난 기록**: 저장한 과제를 날짜별로 봐요(완료 수, 아직 안 한 학생). 눌러서 들어가면 늦게 낸 학생을 그 안에서 체크할 수 있고, `다시 열기`로 체크 화면에 되돌릴 수도 있어요
- `⋯` 버튼: 이름 바꾸기, 저장만 하기, 체크 모두 지우기, 과제 삭제
- 전자칠판에서 한 번 눌렀는데 두 번 눌린 것처럼 들어와도 한 번만 처리해요

### 번호 뽑기
- `+ 새 뽑기` → 이름(예: 10월 자리)과 범위(1~학생 수 / 1~100 / 직접) 정하기
- **뽑기**: 학생이 자기 이름을 누르면 2초 뒤 번호 공개. 뽑은 학생은 회색 + 번호 표시
- **결과**: 번호별로 누가 뽑았는지. `선생님: 눌러서 취소` 를 켜고 칸을 누르면 그 학생만 다시 뽑을 수 있어요
- `⋯` 버튼: 결과 글자로 복사, 이름 바꾸기, 전체 다시하기, 삭제

### 수학 확인
- 월요일 아침에는 지난 금요일, 연휴 다음 날에는 연휴 전 마지막 등교일 기준이에요.
- 주말·공휴일(대체공휴일 포함)은 자동으로 빠져요. **설날·추석·재량휴업일·방학**은 우리 반 탭 "등교 안 하는 날"에 적어 주세요.
  분수 연산 마스터 교사 화면에 저장한 "등교 안 하는 날"도 자동으로 합쳐져요.
- **"했다"로 보는 기준**: 그날 분수 연산 마스터에 **접속해서 화면을 켰거나**, 연습·도전을 **시작했으면**(중간에 그만둬도) 했다고 봐요. 연습·도전 기록이 없어도 접속만 했으면 "했다"예요. 이런 학생이 있으면 화면에 "접속만 한 ○명 포함"이라고 나와요.
- **누적(벌 대상)**: **누적 세기 시작일**(처음 값 10/8)부터 등교일마다 수학을 안 한 날을 학생별로 **합계**로 세요(연속이 아니라 합계). 접속만 해도 한 날로 세요.
  - 누적이 **벌 기준 횟수**(처음 값 3회) 이상이면 수학 확인 화면 **아래쪽에 큰 이름**으로 따로 나와요
  - 벌을 받았으면 그 학생의 **`벌 받음 · 해제`**를 누르세요. 그 날까지의 횟수가 지워지고 **다음 등교일부터 0회에서 다시** 세요. (잘못 누르지 않도록 한 번 더 물어봐요)
  - 1~2회인 학생은 "누적 지켜보기" 줄에 작게 나와요
  - 시작일·기준 횟수는 우리 반 탭 설정에서 바꿀 수 있어요
  - 팝업 화면에는 누적 대상 이름이 크게 나오지만 `해제` 버튼은 사이트에서만 눌러요. 카카오톡에도 "⚠ 누적 ○회 이상" 줄이 들어가요
- **세지 않는 학생**
  - 분수 연산 마스터에 L28~L36 이 생겨서 **10/28 화면(10/27 기록)부터는 "항상 뺄 이름"만 빼고 모두** 세요. 누적도 10/27 기록부터 세요.
  - 10/27 화면까지는 예전처럼 마지막 단계(**L27**)를 통과한 학생(도전 216점 이상)이 자동으로 빠져요
  - 우리 반 탭 "수학 확인에서 항상 뺄 이름"에 적은 학생(처음 값: 전지현, 테스트)도 빠져요
  - 화면 아래 "세지 않음 —" 줄에 누가 빠졌는지 보여 줘요
- **레벨·점수**: 이전 등교일에 한 학생마다 그날 도전 점수(레벨마다 가장 높은 점수)와 연습만 한 레벨을 화면 아래 "레벨·점수"에 보여 줘요.
  - 그날 **처음** 통과 점수를 넘은 레벨은 "⬆ L12 통과 → L13"(레벨 상승)으로 초록색으로 표시하고, 위쪽에도 "⬆ 레벨 상승 ○명" 줄로 점수와 함께 모아 보여 줘요. 팝업에도 똑같이 나와요.
  - 통과 점수는 분수 연산 마스터와 같아요: 만점 − 허용 오답 × 2점 (도전 문제 10개 이하는 1개, 아니면 2개)
- 분수 연산 마스터에서는 **하루에 한 번만** 받아 와요(아침 8:30 카카오톡 알림이 받으면 사이트는 그걸 그대로 써요). 이전 등교일은 이미 끝난 날이라 하루 동안 결과가 안 바뀌어서, 여러 기기가 열어 두거나 설정을 바꿔도 분수 연산 마스터를 다시 부르지 않아요.
- **새로고침** 버튼을 누를 때만 분수 연산 마스터에서 새로 받아요. 오늘 마지막 단계(L27)를 통과한 학생, 명단이 바뀐 것은 새로고침하거나 다음 날 반영돼요.
- "오늘 무료 사용량이 끝났어요"가 나오면 분수 연산 마스터 쪽 한도 문제예요. 매일 오후 4시에 초기화돼요. 그동안은 마지막으로 받은 결과를 보여 줘요.

### 내보내기 · 백업

- **전체 백업 받기 / 백업 파일로 되돌리기**: 명단·설정·과제·뽑기 전부

같은 Firebase 프로젝트로 반마다 따로 쓰려면 주소 뒤에 `?room=이름` 을 붙이세요. (예: `https://사이트주소/?room=5-3`)

## 3. 알림 받기 (수학 확인을 자동으로)

매번 사이트에 들어가지 않아도 되도록 두 가지를 만들어 두었어요. 하나만 써도, 둘 다 써도 돼요.

| 방법 | 어떻게 | 준비 |
| --- | --- | --- |
| **카카오톡** | 평일 오전 8:30에 카카오톡 "나와의 채팅"으로 안 한 학생 이름이 와요 | 아래 3-1 (카카오 설정 10분, 처음 한 번) |
| **학교 PC 팝업** | 평일 오전 8:30에 수학 확인 화면이 작은 창으로 떠요 | 아래 3-2 (파일 더블클릭) |

두 방법 모두 사이트와 같은 계산을 써서, "항상 뺄 이름"(10/27 화면까지는 L27 통과 학생도)이 똑같이 빠져요.

### 3-1. 카카오톡으로 받기

선생님 카카오톡으로만 와요(학생·학부모에게는 안 가요). 서버 대신 GitHub Actions가 매일 아침 자동으로 돌려요.

**① 카카오 개발자 앱 만들기** (<https://developers.kakao.com> → 카카오 계정으로 로그인)
1. **내 애플리케이션 → 애플리케이션 추가하기**: 앱 이름 예) `우리반알림`
2. **카카오 로그인 → 사용 설정**을 **ON**
3. 같은 화면의 **Redirect URI**에 `https://example.com/oauth` 등록
4. **동의항목**에서 `카카오톡 메시지 전송(talk_message)`을 **선택 동의**로 설정
5. **앱 → 플랫폼 키 → REST API 키**를 눌러 **REST API 키** 값과 **클라이언트 시크릿** 값을 복사해 둡니다 (시크릿이 꺼져 있으면 켜기)

> 카카오 화면 이름이 바뀌어 있을 수 있어요. 막히면 화면을 캡처해서 알려 주세요.

**② 토큰 받기** (컴퓨터에서 한 번만)
1. 이 저장소의 `tools/kakao-token.py`를 내려받아 명령 프롬프트에서 `py tools\kakao-token.py`
2. REST API 키 → 클라이언트 시크릿 입력 → 열리는 카카오 화면에서 **동의하고 계속하기**
3. 이동한 `example.com` 페이지 **주소창의 전체 주소**를 복사해 붙여넣기
4. 카카오톡에 시험 메시지가 오고, 화면에 **리프레시 토큰**이 나와요 (남에게 보여주지 마세요)

**③ GitHub에 넣기** (저장소 → Settings → Secrets and variables → Actions)
- **Secrets** (New repository secret) 3개: `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`, `KAKAO_REFRESH_TOKEN`
- **Variables** (Variables 탭) 1개: `SITE_URL` = 우리 반 사이트 주소 (카톡 메시지의 "수학 확인 열기" 버튼이 이 주소로 가요)

**④ 시험해 보기** (저장소 → Actions → "수학 안 한 학생 카카오톡 알림" → Run workflow)
1. `dry_run`만 켜고 실행 → 초록 체크면 설정이 맞는 거예요 (카톡은 안 가요)
2. `force`만 켜고 실행 → 주말이어도 카카오톡이 한 통 와요

이후에는 평일 오전 8:30(한국 시간)에 자동으로 와요. 주말·공휴일·"등교 안 하는 날"에는 안 보내요.

- GitHub 정책상 아주 가끔 몇 분~수십 분 늦게 돌 수 있어요.
- 이 저장소는 공개라서 실행 기록이 모두에게 보여요. 그래서 **학생 이름은 기록에 남기지 않고 인원 수만** 남겨요.
- 카카오 토큰은 60일마다 갱신해야 하는데, 갱신된 토큰은 자동으로 암호화해서 보관해요. 직접 할 일은 없어요.
- 저장소에 60일 동안 아무 변경이 없으면 GitHub가 자동 실행을 멈출 수 있어요(공개 저장소 규칙). 메일이 오면 Actions 탭에서 다시 켜세요.
- 실패하면 보통 GitHub에서 선생님 메일로 알려 줘요 (GitHub 알림 설정이 켜져 있다면).

### 3-2. 학교 PC 바탕화면 팝업

1. 이 저장소의 `school-pc` 폴더를 학교 PC에 내려받아 **자리를 정해 두세요** (예: `문서\우리반`)
2. `수학확인_팝업_등록.bat` 더블클릭 → 사이트 주소 입력 → **창 위치 고르기**(1 오른쪽 위 · 2 오른쪽 아래 · 3 왼쪽 위 · 4 왼쪽 아래 · 5 가운데) → (원하면) 로그인할 때도 띄우기 `y`
3. 시험: 같은 폴더의 `open_math_popup.bat` 더블클릭 → 고른 자리에 작은 창이 떠요

평일 오전 8:30에 PC가 켜져 있고 로그인되어 있어야 떠요. 끄려면 `수학확인_팝업_해제.bat`. 폴더를 옮기면 등록 파일을 다시 실행하세요.
창은 열 때마다 **고른 모서리(작업 표시줄 위)**로 알아서 자리를 잡아요. 위치를 바꾸려면 등록 파일을 다시 실행해서 다른 번호를 고르세요.
(주소 뒤에 `?popup=1&pos=br`처럼 붙이면 어느 브라우저에서도 같은 작은 화면이 보여요. `pos`는 `tr` `br` `tl` `bl` `c` 중 하나예요.)

## 4. 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| "처음 설정이 필요해요" 화면 | 1-2 의 `firebase-config.js` 값이 비어 있어요. 넣고 1~2분 뒤 새로고침 |
| "Firebase 규칙 때문에 저장하지 못했어요" | 1-1 의 3번(규칙 붙여넣기 → 게시)을 다시 확인 |
| 빨간 띠 "인터넷 연결이 끊겼어요" | 연결되면 자동으로 저장돼요. 번호 뽑기만 연결 후에 |
| 수학 확인에 "반 코드를 찾을 수 없어요" | 우리 반 탭의 반 코드 6글자 확인 |
| 다른 기기에 안 바뀌어요 | 두 기기의 주소(특히 `?room=`)가 같은지 확인 |

  js/store.js              Firestore 읽기·쓰기 (과제·뽑기·명단·수학 캐시·백업)
  js/app.js                탭 전환, 실시간 구독, 연결 상태 표시
  js/views/*.js            탭별 화면

  js/lib/mathpractice.js   분수 연산 마스터 Firestore REST 읽기

scripts/notify-*.mjs       카카오톡 알림 (설정 읽기 → 수학 계산 → 나에게 보내기, 토큰 암호화 보관)
.github/workflows/         평일 8:30 자동 실행 (math-notify.yml)

Firestore 구조 (`rooms/{room}` 아래):

| 위치 | 내용 |
| --- | --- |
| `rooms/{room}` | 반 이름, 수학 반 코드, 등교 안 하는 날, 수학 제외 이름, 누적 시작일·기준 횟수·해제 기록(`mathCleared`: 번호 → 그 날까지 해제), 명단 `[{id,no,name}]` |
| `rooms/{room}/assignments/{id}` | 과제 이름, `done: {학생id: 시각}` — 칸마다 따로 저장해서 동시에 눌러도 안 겹침. `closedAt` 이 있으면 지난 기록 |
| `rooms/{room}/draws/{id}` | 범위, `picks: {번호: 학생}`, `byStudent: {학생id: 번호}` — 트랜잭션으로 중복 방지 |
| `rooms/{room}/cache/math` | 수학 결과 10분 공유 캐시 |
| `rooms/{room}/cache/mathBase` | 오늘 받은 반 정보·명단·L27 통과·이전 등교일 기록(레벨·점수 포함). 같은 날에는 이걸로 계산해서 분수 연산 마스터를 다시 부르지 않아요 |
| `rooms/{room}/cache/mathDays` | 지난 등교일별 "그날 한 학생" 목록(누적 계산용). 끝난 날은 안 바뀌어서 한 번만 조회해 두면 분수 연산 마스터의 하루 무료 읽기 한도를 아껴요 |

로컬에서 확인 (Node 20+, Java 11+):

```bash
npm install                                    # 테스트용 firebase 패키지
npm test                                       # 단위 테스트 (에뮬레이터 테스트는 건너뜀)

# 에뮬레이터까지 포함한 전체 테스트
npx firebase-tools emulators:exec --only firestore --project demo-classroom "npm test"

# 브라우저로 확인
npx firebase-tools emulators:start --only firestore --project demo-classroom   # 창 1
npm run dev                                                                    # 창 2
# → http://localhost:3000/?emulator=127.0.0.1:8080
node test/e2e.cjs                              # 창 3: Playwright 로 전체 흐름 확인
```
